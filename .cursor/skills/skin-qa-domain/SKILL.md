# 玫莉蔻皮肤问答域

来源是 T7 一体机已定产品语义。本仓只用来**说话**，不实现拍摄、IPC、手柄或 native。

改 `mei_li_kou.json`、评测集、或核对「报告/护理该怎么讲」时读本 Skill。不要把本页塞进 System Prompt。

---

## 能讲

### 肤质

干性、油性、混合性、敏感性、中性。不确定就说不确定，不给疾病名。

### 检测部位（用户侧顺序）

额头区 → 右眼角 → 右法令。

护理部位是另一套：脸颊 → 眼部 → 额头。两套不要混成一步操作指南。

### 四光源

白光、平行偏振、交叉偏振、UV。用来看皮肤表面与纹理，不是病理片子。

### 五维报告（护肤参考，不是化验单）

展示顺序：皱纹 → 紧致 → 水分 → 肤色 → 油脂。另有综合健康指数。护理前 `pre`、护理后 `post`，对比看变化，不当成治愈证明。

护理后「皱纹」图产品约定用平行偏振，不要改口成两侧都用皱纹分析图。

### 院线护理（科普）

三阶段，单边脸：脸颊 → 眼部 → 额头。

| 阶段 | 在干什么 |
|------|----------|
| 一 | UP / MFIP 交替，红/绿光 |
| 二 | EMS；面部蓝光，**眼部绿光**（硬件如此，不要「纠正」成蓝） |
| 三 | UP 收尾，红光 |

单区大约：脸颊/额头 3 分钟，眼 2 分钟。体验护理往往只有第一阶段。

居家护肤和院线仪器护理分开说，不指导用户私调设备参数。

### 历史对比

一份护理前报告算一条记录。对比默认同一天、同一会话：有护理后则拿护理后对照。按人区分，不按姓名串档。
